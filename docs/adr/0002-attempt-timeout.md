# ADR 0002. 실행 제한 시간의 시작점과 슬롯 대기

**상태** 채택

## 배경

단일 슬롯 Agent에서는 앞선 작업 때문에 다음 Job이 기다릴 수 있다. 사용자에게 실행 시간을 얼마나 보장하는지는 제한 시간을 어느 시점부터 재는지에 따라 달라진다.

## 결정

`timeout_seconds`는 Attempt 한 번의 실행 제한 시간이다. Agent가 슬롯을 확보하고 해당 Attempt를 접수한 시점부터 잰다. 슬롯 대기와 재시도 대기에는 이 시간이 흐르지 않는다. 새 Attempt를 시작하면 같은 제한 시간을 새로 적용한다.

초기 설계에는 큐 대기 기한이 없다. 슬롯이 계속 사용 중이면 같은 Attempt로 대기하며, 호출자는 이때도 Job을 취소할 수 있다. 실행 중 제한 시간을 넘기면 해당 Attempt를 `TIMED_OUT`으로 기록하고 Job의 취소·재시도 정책을 적용한다.

## 검증 사례

제한 시간이 10초인 작업이 슬롯을 15초 기다려도 대기만으로 시간 초과가 발생하지 않아야 한다. Agent가 이 작업을 접수하면 그때부터 10초를 적용한다. 슬롯 대기 중 취소한 작업은 이후 슬롯이 비어도 추론을 시작하지 않아야 한다.
