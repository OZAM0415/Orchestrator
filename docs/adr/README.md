# 아키텍처 결정 기록

각 ADR에는 설계에서 선택한 동작과 그 이유, 구현 시 확인할 사례를 기록한다. **채택**은 설계에 합의했다는 뜻이다. 구현 진행 상황은 프로젝트 README에서 확인한다.

| 번호 | 결정 | 상태 |
| --- | --- | --- |
| [0001](0001-attempt-recovery.md) | 시작 응답 유실과 Agent 재시작 시 Attempt 복구 | 채택 |
| [0002](0002-attempt-timeout.md) | 실행 제한 시간의 시작점과 슬롯 대기 | 채택 |
| [0003](0003-input-validation.md) | 공통 실행 정책과 모듈별 입력 검증의 책임 | 채택 |
| [0004](0004-job-ownership.md) | Job 소유권과 멱등성 키의 적용 범위 | 채택 |

새 결정에는 다음 네 자리 번호를 부여한다. 오탈자와 설명 보완은 같은 문서에서 Git 이력으로 관리한다. 이미 채택한 동작을 바꿀 때는 새 ADR을 작성하고, 이전 ADR의 상태를 **대체됨**으로 바꾼다. 두 문서에 서로의 링크를 남기고 이 목록도 갱신한다.
